# USACO Solutions

My solutions to USA Computing Olympiad problems, working through usaco.guide.
Started November 2026 in the Bronze division.

## Structure

One folder per problem, containing:
- `solution.py` — my solution
- `test.txt` — the sample input from the problem statement

To run a solution:

```bash
cd bronze/problem-name
python solution.py < test.txt
```
